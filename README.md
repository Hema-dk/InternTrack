# InternTrack

Internship tracking app built with React (JSX), CSS and localStorage.

## Run it
1. Install Node.js (https://nodejs.org) if you don't have it
2. In this folder, run:
   npm install
   npm run dev
3. Open the link it prints (usually http://localhost:5173)

## Build for deployment
   npm run build      (output goes to the dist/ folder)

## Pages
Home, Applications, Deadlines, Analytics, Settings (profile, theme, import/export), About.
Navigation uses URL hashes (#home, #analytics...) so the browser back button works.
